Dessert guide · sample street
Hover a shop to stop the street. Drag, swipe or scroll sideways to browse.

Use it in a project

One script, no build step, no dependencies. Add the element, give it a list of shops, and it handles the loop, drag, wheel, keyboard focus, tooltips and dark mode.

Drop in

<script src="storefront-street.js"></script>

<storefront-street speed="36" height="300">
  <script type="application/json">
    [
      { "name": "Crumb & Co.", "type": "shop", "color": "#b8433b", "accent": "#2f7d55",
        "meta": "Bakery · Valencia St", "note": "Kouign-amann, sells out by 10am." },
      { "name": "Halfmoon", "type": "cafe", "accent": "#c8303a" }
    ]
  </script>
</storefront-street>

Drive it from code

const street = document.querySelector('storefront-street');
street.stores = await (await fetch('/api/places')).json();

street.addEventListener('store-select', e => {
  router.push(`/places/${e.detail.store.id}`);
});

street.pause();  street.play();  street.scrollToStore('halfmoon');

Building types

shopBrick front, scalloped awning
cafeOval medallion sign, roof rail
walkupApartments, fire escape, shop below
kioskStriped walk-up window
galleryWide sign, long glowing window
modernDark facade, picket fence
cottageGabled roof, pastel glow

Street props go in before: tree, lamp, gap, or { "type": "signpost", "label": "Main St" }. Leave it out and props are picked for you.

Shop fields

FieldWhat it does
namePainted on the sign and shown in the tooltip
typeOne of the building types above (default shop)
color / accent / trimFacade, sign or awning, and frame colors
sub, number, badge, markSmall sign text, street number, badge word, logo glyph
meta, noteTooltip lines
hrefMakes the building a link instead of a button
width, height, floorsOverride the template's proportions
beforeProps drawn to the left of this shop

Element attributes

AttributeDefaultNotes
speed36Pixels per second. 0 makes it a drag-only street
height300Street height in px; widths scale with it
directionleftright reverses the drift
themeautoFollows data-theme on <html>, then the OS. Dark turns it into a night street
propsautonone turns off automatic trees and lamps
srcURL of a JSON file with the shop list
pausedBoolean. Reduced-motion users get a still street unless motion="always"

Restyle from outside with CSS variables such as --ss-ink, --ss-lit, --ss-glass, --ss-font-script and --ss-font-block, or register a new building with StorefrontStreet.templates.myType = (store, rand) => ({ w, top, body }).
