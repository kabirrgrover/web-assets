web-assets / topic-cards

Every chat becomes a card.

One agent, many threads. Swipe the chat sideways and it blurs back while your topics fan out as soft gradient cards. Pick one to jump in, or open Cards to see what the agent is still working on.

  • SwipeDrag the chat sideways, scroll with a trackpad, or tap the pill above the composer.
  • OpenTap the centered card. Tap a side card to bring it to the middle first.
  • CardsThe last card, or tap the agent's face, opens Working and Bookmarked.
  • SendA message on the main feed starts a new topic. The agent's eyes show it's working.

Reusable component

Drop it into any project

One script, one tag. Hand it an array of topics with their messages; colors are optional and fall back to a palette generated from the title.

It never calls a model. Listen for topic-send, call your backend, then hand the answer back with reply().

autoplayLoops a walkthrough until someone touches it

<script>
  const chat = document.getElementById('chat');
  chat.topics = [
    {
      title: 'Wedding toast',
      date: 'Oct 6 · 9:40 PM',
      colors: ['#6f6cf2', '#d9dcff', '#4f46e5'], // optional
      working: true,
      bookmarked: false,
      messages: [
        { from: 'user',  text: 'Toast for Jamie, under a minute' },
        { from: 'agent', text: 'Open with **the night you met**…' }
      ]
    }
  ];

  chat.addEventListener('topic-send', async (e) => {
    const answer = await myAgent(e.detail.text);   // your backend
    chat.reply(e.detail.id, answer);
  });
</script>
