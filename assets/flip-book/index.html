Drag a page, click either side, or focus the book and use the arrow keys.

Drop it in

One script, one tag. Every direct child becomes a page, read in order: front cover, inside cover, then left/right spreads, ending on the back cover.

<!-- load once -->
<script src="flip-book.js"></script>

<flip-book autoplay interval="1800" ratio="0.72">
  <section data-hard>Cover</section>
  <section>Inside cover</section>
  <section>Page 2</section>
  <section>Page 3</section>
  <section data-hard>Back cover</section>
</flip-book>

Pages are CSS size containers, so size type with cqw and cqh and the design scales with the book at any width.

Attributes

AttributeDefaultWhat it does
autoplayoffTurns pages on a timer. Pauses on interaction and when scrolled off screen.
interval1800Milliseconds between autoplay turns.
duration900Milliseconds per turn.
segments16Strips per page. Higher is a smoother curl and more DOM. 12 to 20 is the sweet spot.
curl70Degrees the outer edge leads the spine mid-turn. 0 gives a stiff card flip.
loopon with autoplayAt the end, riffles back to the cover. Set loop="false" to stop.
resume5000Idle milliseconds after user input before autoplay resumes.
ratio0.72Page width divided by height.
tilt0Tips the book back in degrees for a tabletop look.
start0Spread to open on. 0 is closed on the front cover.
no-dragDisables drag to turn. Clicks and keys still work.
no-centerKeeps the closed book in place instead of sliding it to center.
data-hardOn a page: that leaf turns stiff, like a cover board.

Control it

const book = document.querySelector('flip-book');

book.next();          // turn forward
book.prev();          // turn back
book.goTo(3);         // riffle to spread 3
book.pause(); book.play();

book.spread;          // current spread, 0 = closed
book.spreads;         // total spreads

book.addEventListener('flip', e => console.log(e.detail));
// { spread, spreads, direction }  fires as a turn starts
book.addEventListener('flipend', e => console.log(e.detail));

Theme the paper with --fb-paper, the stack edge with --fb-edge and the drop shadow with --fb-shadow.

React / Next

// load once on the client, e.g. in a layout
'use client';
import { useEffect, useRef } from 'react';

export function Book({ children, ...props }) {
  const ref = useRef(null);
  useEffect(() => { import('./flip-book.js'); }, []);
  return <flip-book ref={ref} {...props}>{children}</flip-book>;
}

// <Book autoplay="" interval="2000"><section>…</section></Book>

The element reads its pages once, on first connect. To swap content later, render a new <flip-book> with a different key.

How it works

Each leaf is a front and back face. While a leaf turns, it is swapped for a chain of nested strips, each one rotated a little further than its parent, so the outer edge leads and the paper bends. Every strip carries a slice of the page and gets shaded by its angle. At rest the leaf goes back to two flat faces, so text stays crisp and the DOM stays light.

Content is cloned into the strips the first time a leaf turns. Keep pages visual; live inputs and video inside a page will not mirror into the curl.
