Redline edits, live

A chat response that visibly revises itself: cut filler, lead with the answer, then clean up the table one rule at a time.

    How it plugs in

    Stream the draft as usual. When it finishes, a fast editor model returns revision passes. Redline animates them, then leaves the clean answer in place. Users can skip at any point.

    Edits are plain CriticMarkup, which models write reliably. Structural changes (moves, alignment, new rows) are small JSON ops.

    Figures in this demo are sample data from the reference video, not verified.
