Agent Timeline

A live activity timeline for a team of AI agents. Hover a bar to see its steps, click Needs you to approve, and watch handoffs draw themselves. Demo runs at accelerated time.

Drop it in

One file, no dependencies, no build step. It's a standard web component, so it works in plain HTML, React, Next.js, Vue or Svelte.

<script src="agent-timeline.js"></script>
<agent-timeline id="tl" window="30"></agent-timeline>

<script>
  const tl = document.getElementById('tl');
  tl.setData({
    agents: [
      { id: 'res', name: 'Researcher', model: 'Opus 5.5', avatar: { glyph: 'burst', color: '#d4683f' } },
      { id: 'ops', name: 'Ops', model: 'Gemini 3.8 Flash', avatar: { glyph: 'spark', color: '#2f6bf0' } },
    ],
    tasks: [
      { id: 'a', agent: 'res', title: 'Competitor pricing', icons: ['google', 'notion'],
        startMin: -28, endMin: -19, status: 'done' },
      { id: 'b', agent: 'res', title: 'Customer interviews', icons: ['notion', 'slack'],
        startMin: -9, status: 'running', steps: ['Read 14 interview notes', 'Grouping quotes by theme'] },
      { id: 'c', agent: 'ops', title: 'Rotate API keys', icons: ['stripe', 'github'],
        startMin: -11, status: 'needs-input',
        prompt: { title: 'Rotate API keys', body: 'Rotate the production Stripe and OpenAI keys?' } },
    ],
  });

  tl.addEventListener('task-approve', (e) => {
    // call your backend here; the bar switches to running unless you e.preventDefault()
    console.log('approved', e.detail.task.id);
  });
</script>

React

import './agent-timeline.js';
import { useEffect, useRef } from 'react';

export function AgentsPanel({ agents, tasks, onApprove }) {
  const ref = useRef(null);
  useEffect(() => { ref.current?.setData({ agents, tasks }); }, [agents, tasks]);
  useEffect(() => {
    const el = ref.current;
    const h = (e) => onApprove?.(e.detail.task);
    el.addEventListener('task-approve', h);
    return () => el.removeEventListener('task-approve', h);
  }, [onApprove]);
  return <agent-timeline ref={ref} window="30" />;
}

Task fields

FieldTypeWhat it does
idstringUnique key. Auto-generated if missing.
agentstringAgent id this bar sits on.
titlestringBar label.
statusenumrunning, done, failed, needs-input, queued
start / endms or DateTimestamps. Leave end empty for live tasks; they grow to "now".
startMin / endMinnumberShortcut: minutes relative to now. -9 means 9 minutes ago.
iconsstring[]Tool keys shown before the title.
stepsstring[]Bullets in the hover tooltip.
afterstring[]Task ids this depends on. Draws a dashed handoff link.
promptobject{ title, body, approveLabel, rejectLabel } for the approval popover.

Methods and events

NameWhat it does
setData({agents, tasks})Replace everything.
addTask(task)Add a bar. Returns its id.
updateTask(id, patch)Change status, title, steps. Setting done or failed stamps the end time.
completeTask(id, handoff?)Finish a task and optionally start a linked follow-up on another agent.
removeTask(id), addAgent, removeAgent, clear()Housekeeping.
windowMinutes, speed, rangesVisible window (default 30), clock multiplier, and the presets the "Last 30m" pill cycles through.
task-approve, task-rejectCancelable. Call preventDefault() to manage state yourself.
task-click, task-hoverFires with e.detail.task.

Attributes and styling

Attributes: theme (light, dark, or omit to follow the page), window, speed, title, row-height. CSS hooks: --at-font, --at-radius, --at-label-width, and ::part(card).

Built-in icon keys are neutral monogram tiles. Swap any for a real logo with AgentTimeline.registerIcon('notion', { src: '/logos/notion.svg' }), or pass { svg } or { label, bg, fg }.
