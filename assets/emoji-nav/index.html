Emoji Nav

Links sit quiet in light grey. Point at one and it turns to ink while an emoji springs up beside it, tilted like a sticker. Wrap any links in <emoji-nav> and give each a data-emoji. Works with mouse, keyboard focus, and the current page.

OptionDefaultWhat it does

      
        
data-emojiOn each link. The emoji that pops in.

        
data-iconOn each link. Any image URL instead of an emoji.

        
emoji-setfluentfluent loads Microsoft's 3D emoji (MIT) so it looks the same on every OS. native uses the system font. Fluent falls back to native if an image fails.

        
emoji-basejsDelivrSelf-host the Fluent images: a folder of <codepoints>.webp.
