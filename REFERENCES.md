# References

Sites I like and come back to for ideas, components and craft. Not mine, just good.

## Components and interactions

| Site | What it is |
|---|---|
| [React Bits](https://reactbits.dev/get-started/index) | Free animated React components: text effects, backgrounds, cards, carousels, navs. Every one has a live demo. |
| [Bencho](https://bencho.dev/) | Small React UI elements and animated effects you can play with, tweak and drop into an app. |
| [Shapeshift](https://lab.anishfn.ink/shapeshift) | React input that matches a typed sentence to one of your components, pulls the data out and renders it pre-filled. |

## Isometric figure skills

AI skills that turn a one-line description into an interactive, hand-drawn isometric figure. Useful for explainers and product pages.

| Site | What it is |
|---|---|
| [Anatomy](https://skills.wheresryan.sh/anatomy) | Claude Code skill: an idea becomes a live isometric drawing of a machine that does it. 33-figure gallery, A4 prints, React and custom-element versions. |
| [Anatomy Reveal](https://www.typingmind.com/skills/annnguyentt-anatomy-reveal) | Builds any physical object as a modular isometric figure, then makes a dissection page and a short product-reveal video. MIT. |
| [Colorfigures](https://april-zhu.com/colorfigures) | Claude skill that turns an everyday object into an interactive, hand-inked isometric HTML figure. MIT. |
